## 1. 무엇이 문제였나 (증거)

도면(`애지중지_map.pdf`) ↔ 우리 시드 ↔ Simulation 이 읽는 DB 는 **좌표가 전부 일치**한다
(매대 1,684 · 차지 칸 10,612 · 상품 배치 4,970 — 09-02 전수 대조). 그런데 화면은 달랐다:

| 화면에서 보이던 것 | 진짜 원인 |
|---|---|
| 1F 행사상품 블록 위에 분홍 매대가 겹침 | 행사 블록이 D존 location 좌표 범위(bbox) **안**이라 D색으로 칠해짐 — 41칸 |
| 3F 홈/가전 줄에 사각형이 2개 아니라 3개 | **A/S센터 블록**이 B존 bbox 안 → B색 매대로 — 34칸 |
| 2F 행사 기둥 아래 초록 조각 · 3F 화장실 옆 초록 띠 | 같은 원인 — 2F 행사 7칸, 3F 화장실 블록 12칸 |
| 1F 좌측 벽 매대가 안 보임 | 매대 30개(A·D·F)의 접근 지점이 x=2 라 존 bbox 가 x=2 부터 → 몸체 칸 x=0,1 이 bbox 밖 → **벽으로 오인돼 안 칠함** |

`StoreScene.ts` 의 규칙이 이랬다: *통행불가 칸마다 가장 가까운 location(≤8)의 존 색을 칠하되, 그 존의 bbox 안일 때만.* 코드 주석에 *"진짜 깊은 매대 칸 67개 — 1층 F1-D(x26~32,y29~33), 3층 F3-B(x2~8,y51~55)"* 라고 적혀 있는데, 그 67칸이 우리 행사 블록과 A/S센터다. **데이터가 없어서 추측했고, 추측이라 틀렸다.**

## 3. pull 뒤에 해야 할 것 — 셋

### ① DB — 컬럼 둘 + map_cells 재적재

기존 DB(시드가 이미 들어 있는 곳)에는 **마이그레이션 한 파일**이면 된다:

```bash
MYSQL="/c/Program Files/MySQL/MySQL Server 8.0/bin/mysql.exe"
"$MYSQL" --force --default-character-set=utf8mb4 -h127.0.0.1 -P3307 -uroot -p storeflow_db < db/migration_map_cells_kind_0902.sql
```

- `--force` 를 꼭: 컬럼이 이미 있으면 ALTER 가 오류를 내는데 **무해**하다 — 그대로 넘어가 재적재까지 간다.
- stocks·재고 이력·구매·채팅은 **안 건드린다.** map_cells 21,375행만 지우고 다시 넣는다.
- 새로 만드는 DB 는 이 파일이 필요 없다 — `schema_v2.sql` 이 이미 두 컬럼을 갖고 `world_seed.sql` 이 채운다.

검산:
```sql
SELECT kind, COUNT(*) FROM map_cells GROUP BY kind;
-- AISLE 10751 · SHELF 6736 · FACILITY 3876 · TRANSIT 12 이면 성공
```

### ② 백엔드 재시작

엔티티에 컬럼이 늘었다 — 안 올리면 `cells[]` 에 `kind` 가 없어 프론트가 **조용히 옛 추측으로 폴백**한다(오류 없이 예전 그림). 재시작 뒤 확인:

```
GET /api/map/floors/1  →  cells[0] 에 "kind": "SHELF", "shelfZone": "F1-F" 가 보여야 한다
```

### ③ Simulation dev 서버 재시작

`npm run dev` 를 껐다 켠다(타입·모듈이 바뀌었다). 켠 뒤 1F 를 보면 **좌측 벽 매대 30개**가 보이고, 행사상품 블록 위에 분홍 매대가 없고, 3F 아래줄 하늘색 사각형이 **둘**이면 성공.

## 4. 영향 — 없는 것과 남은 것

- **DES·학습·T17: 영향 없음.** 추가 컬럼이고 `map_cells` 는 시뮬레이터·학습이 읽지 않는다. 동선 솔버(백엔드 A*)는 `passable`·`transit_id` 만 보므로 경로도 그대로.
- **남은 것 (별건)**
  - `floorAmenities.ts` 의 시설·구역 좌표(화장실·입구·베이커리·시식…)는 여전히 도면과 어긋나 있다(예: 베이커리 x41 vs 도면 x54, 시식 코너 높이 4 vs 12). 다음 단계에서 우리 `map_layout` 의 시설 사각형에 이름을 붙여 **그 파일을 생성물로 교체**한다 — 그때 이름표까지 도면과 맞는다.
  - 1F 도면 하단 4.6행(고객센터 아랫부분·입구 옆 벽)이 우리 격자(75행) 밖이다. 매대는 하나도 안 잘렸고 손님 동선과 무관하지만, 입구 POI 를 놓을 때 1F 만 격자 높이를 늘린다.
