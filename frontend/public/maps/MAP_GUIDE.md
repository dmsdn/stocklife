# 매장 지도 이미지 준비 가이드

## 핵심 원리

지도는 **그림 위에 좌표(x, y)로 핀을 찍는 방식**입니다. 그림 자체는 그냥 배경 이미지일 뿐이고,
실제로 "몇 번째 칸에 핀을 찍을지"는 이미지 위에 가상의 격자(그리드)를 몇 칸으로 나눌지에
달려있습니다. 그림과 좌표 체계만 맞으면 어떤 그림이든 그대로 씁니다.

## 1. 이미지 파일

- 위치: `public/maps/floor-1.png` (2층이 있으면 `floor-2.png`, 이런 식으로)
- 매장을 위에서 내려다본 평면도 형태 권장 (아이소메트릭/3D 말고 탑뷰)
- 포맷: PNG 또는 JPG, 가로세로 비율은 실제 매장 모양과 맞으면 됨 (정사각형일 필요 없음)

## 2. 격자(그리드) 정하기

그림을 가로 N칸 × 세로 M칸으로 나눈다고 상상하고, 그 N과 M을 정해주세요.
예를 들어 그림을 가로 24칸 × 세로 16칸으로 나누기로 했으면:

```ts
// lib/map-config.ts
{ floorNo: 1, image: "/maps/floor-1.png", gridWidth: 24, gridHeight: 16 }
```

이렇게 등록하면 됩니다. **실제로 그림 위에 선을 그릴 필요는 없습니다** — 그냥 "이 그림을
24×16으로 나눈다"는 약속만 코드에 알려주는 것뿐입니다.

## 3. 상품 위치 좌표 넣기

각 상품이 매장의 어느 칸에 있는지를 x(왼쪽에서 몇 칸), y(위에서 몇 칸)로 넣어주면 됩니다.
지금은 `lib/mock-products.ts`의 각 상품에 `location: { floorNo, x, y }`로 들어가 있습니다
(제가 임의로 채워둔 좌표라 실제 그림이랑 안 맞을 수 있어요 — 실제 그림 완성되면 눈으로 보면서
좌표만 다시 맞추면 됩니다. 예를 들어 "이 상품은 입구에서 가로로 3칸, 세로로 5칸 들어간 자리"면
`{ floorNo: 1, x: 3, y: 5 }`).

## 4. 실제 백엔드 연동 시점에는

지금은 이 좌표를 프론트에서 목업으로 들고 있지만, 나중에 실제 매장 재고 위치 API
(`GET /api/products/{skuId}/inventory`가 돌려주는 x, y)로 연결하면 이 좌표를 그쪽에서 받아오게만
바꾸면 됩니다 — 지도 컴포넌트(`components/domain/store-map.tsx`)는 좌표만 받으면 되도록
설계해뒀어서 손댈 필요가 없습니다.

## 요약

1. `public/maps/floor-1.png`에 그림 넣기
2. `lib/map-config.ts`에 그 그림을 몇 칸×몇 칸으로 볼지 적기
3. 상품마다 몇 번째 칸에 있는지 x, y로 적기

이 세 가지만 맞으면 핀·동선이 그림 위에 자동으로 올라갑니다.
